# Copy this file to "proxies.txt" to use multi-connection mode (-n).
# One line = one connection. The number of usable lines should match -n.
#
#   direct              -> no proxy (current network/tunnel)
#   host:port           -> SOCKS5 proxy (each line = a different exit IP)
#   scheme://host:port  -> full URL (e.g. socks5h://host:1080, http://host:3128)
#
# Routing each connection through a different IP can bypass the throttling that
# some servers apply PER-IP. Check a proxy's exit IP with:
#   curl https://api.ipify.org --socks5-hostname host:port
#

direct
